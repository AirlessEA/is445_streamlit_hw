# IS 445 Streamlit Homework: Bigfoot Reports

Streamlit app with two Altair visualizations of the BFRO Bigfoot reports dataset
(https://raw.githubusercontent.com/UIUC-iSchool-DataViz/is445_data/main/bfro_reports_fall2022.csv).

1. Reports per year linked to a US map (drag across the bar chart to filter the map).
2. Histogram of the weather on the day of each report, controlled by a radio button and a season multiselect.

Run locally with `streamlit run streamlit_app.py`.
